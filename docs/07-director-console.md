# REQ-DIRECTOR 3D 导演台

> 本文替代原 `doc/director-console.md`。原文是实现前的原型需求，本文按当前实现重新梳理，并把已完成的项目从"本期不做"里移出。

## 1. 目标

在 3D 场景中摆放、调整**角色**与**机位**，并在「导演视角」与「机位视角」之间切换预览，服务于内容拍摄前的场景调度与运镜预演。

技术上，它同时是 [REQ-3DEDITOR](06-three-editor.md) 的验证用例：证明把 `three-editor` 拆成组件之后，能够只取其中的视口 + 编辑器内核，套一层完全不同的业务界面。

页面：`/3d-scene`。

## 2. 整体布局

```
┌───────────────────────────────────────────────────────────┐
│  3D导演台            [导演视角 | 机位视角]                    │
├───────────┬───────────────────────────────────┬─────────────┤
│           │                                   │             │
│  场景面板  │        3D 场景渲染区域              │  属性面板    │
│ (图形列表) │                                   │ (场景/角色/  │
│           │        ┌─────────────────┐         │   机位)     │
│           │        │  悬浮工具栏       │         │             │
│           │        └─────────────────┘         │             │
└───────────┴───────────────────────────────────┴─────────────┘
```

- 顶部条：标题 + 视角切换 Tab。
- 左侧：场景面板，固定 224px。
- 中间：3D 视口，内部叠加取景框、角色标签、悬浮工具栏。
- 右侧：属性面板，固定 288px；三个面板互斥展示。

导演台复用 `ThreeEditor` 上下文与 `EditorViewport`，其余界面全部是导演台自己的组件。编辑器实例用 `createEditor("director-console")` 创建，自动保存与 `/three-editor` 隔离。

## 3. 功能需求

### 3.1 视角切换

- 两个 Tab：**导演视角**、**机位视角**。
- 导演视角：自由相机，用于整体编排、拖拽摆放。
- 机位视角：把视口相机切换为某个已添加机位，预览该机位的实际取景。
- 切换 Tab **只影响渲染区域**使用的相机与交互方式，左右面板内容不变。
- 当某机位正作为视口相机时，它自己的机位模型必须隐藏，避免挡住画面。

### 3.2 左侧场景面板

- 展示 `editor.scene` 顶层对象的**扁平列表**，按添加顺序排列。
- **不提供搜索框，不做分组分类。**
- 每一项：名称（无名时显示类型）+ 可见性切换（眼睛图标）。
- 点击列表项 = 选中对应对象，右侧切换到相应属性面板。
- 列表为空时显示引导文案「暂无图形，点击下方工具栏添加角色或机位」。
- 全景天空球属于 `editor.backdrop` 而非 `editor.scene`，**不出现在列表中**。
- 可见性切换必须走 `SetValueCommand`，从而可撤销。

### 3.3 悬浮工具栏

位于视口底部居中，包含：

| 控件 | 行为 |
|---|---|
| 变换模式 | 下拉选择：移动 / 旋转 / 缩放，切换视口 Gizmo 形态；未选中对象时不可用 |
| 添加角色 | 预设「男性素体」「女性素体」（Mixamo FBX 素体） |
| 添加图形 | 预设立方体 / 球体 / 圆柱体 / 环状体 / 圆锥 / 棱锥，以及「上传文件」导入本地模型 |
| 添加机位 | 新增透视相机，并加载 `camera.glb` 作为机位在场景中的可见标志物 |
| 画幅比例 | 下拉选择 `21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16`，`auto` 表示不显示取景框 |
| 撤销 / 重做 | 走编辑器 `History`，按钮按可用性禁用 |
| 清空场景 | 清空整个场景 |

约定：

- 新增对象自动加入左侧列表、自动选中、并把视口聚焦到它。
- 命名自动去重（同类前缀 + 序号，如「机位 2」）。
- FBXLoader / GLTFLoader 必须**按需动态 import**，不进入导演台首屏包。
- 画幅比例按钮**仅在场景中存在机位时显示**；机位被清空时取景框需复位为 `auto`。

#### 3.3.1 角色导入的两个硬性处理

1. **单位缩放**：Blender 导出的 FBX 会把"厘米"约定烘焙进文件，FBXLoader 会把 `object.scale` 设成 0.01。必须把解析结果包进一个 `Group` 包装器，让用户在面板里看到的缩放是自然的 `1.0`。
2. **选中粒度**：包装器需打 `userData.isCharacter` 标记。视口点击角色任意部位（网格、骨骼）时必须冒泡选中整个包装器，否则拖拽只会移动角色的一部分。

### 3.4 视口

- 支持视口内点选对象，与左侧列表选中状态**双向同步**。
- 选中后显示变换 Gizmo，形态跟随当前变换模式。
- 保留视角小工具（轴向指示器 + 重置视角）。
- 支持 Delete 键删除选中对象。
- 角色统一使用无光照（unlit）材质，保证在任意灯光条件下轮廓清晰、颜色可预期。
- 选中角色时叠加骨骼线框，便于姿势调节时定位关节。
- 机位选中时绘制视锥，并在地面上投出视锥覆盖范围（footprint），直观表达"这台机位能拍到哪一片"。

#### 3.4.1 画幅取景框

- 按当前画幅比例在视口中画出取景框，框外区域做模糊 / 压暗。
- 必须是**纯 CSS 叠加层**，不参与 Three.js 视口渲染 —— 这样它不会进入截图 / 出图结果，也不影响渲染性能。

#### 3.4.2 角色标签

- 在角色上方浮动显示名称标签，跟随对象在屏幕上的投影位置。
- 由场景属性面板的「角色标签」开关统一控制显隐。

### 3.5 右侧属性面板（三选一，互斥）

#### 3.5.1 未选中任何对象 → 3D 场景属性面板

- **场景变换**：缩放（滑块 + 百分比）、平移 X/Y/Z、旋转 X/Y/Z。
- **全景背景**：全景图（缩略图，可更换）、天空颜色（拾色器 + hex）。
- **全景球**：水平旋转（滑块 + 角度）、球半径（滑块 + 数值）。
- **地面**：显示开关、高度、透明度。
- **角色标签**：显隐开关。

#### 3.5.2 选中角色 / 图形 → 对象属性面板

- 名称（可编辑）。
- 变换：位置 X/Y/Z、旋转 X/Y/Z、缩放 X/Y/Z，并提供「统一缩放」开关。
- 可见性（与左侧列表联动）。
- 角色额外提供**姿势调节**（见 3.6）。

#### 3.5.3 选中机位 → 机位属性面板

- 名称。
- **机位预览**：实时渲染该机位画面的缩略图。
- **切换机位**：直接把视口切到该机位视角。
- **视野角度（FOV）**。
- **注视目标**：从场景对象中选一个作为 lookAt 目标，机位自动朝向它并持续跟随；或改用**注视坐标**手动指定一个点。
- **手动坐标 / 位置**：直接输入机位位置。

> 三处（左侧列表、视口 Gizmo、右侧面板）的选中态与数值必须**实时双向同步**：任一处修改，其余两处立即更新。

### 3.6 角色姿势调节

- 面板按身体部位分组：身体、躯干、头部、左右肩、左右肘、左右髋等，每组给出若干带角度范围限制的滑块（如「前倾 -45°~45°」「弯曲 0°~140°」）。
- 提供 20 个**姿势预设**：站立、T 型、行走、跑步、坐姿、蹲下、单膝跪、双膝跪、叉腰、倚靠、鞠躬、思考、格斗、踢球、投掷、推进、招手、伸手、抱臂、看手机。
- 预设是**起始姿势**（手工编排，非动捕数据），选中后允许继续用滑块微调。
- 导入角色时需快照绑定姿势（bind pose），保证姿势可以复位。

### 3.7 撤销 / 重做

- 所有改变场景的操作（增删对象、变换、改属性、切可见性）都必须通过编辑器 `Command` 执行。
- 工具栏的撤销 / 重做按钮根据历史栈可用性自动禁用。

## 4. 交互联动表

| 操作来源 | 触发结果 |
|---|---|
| 点击左侧列表项 | 视口中对应对象高亮选中 + 右侧切换为对应属性面板 |
| 视口中点击对象 | 左侧列表对应项高亮 + 右侧切换为对应属性面板 |
| 视口中点击空白 | 取消选中 + 右侧回退为场景属性面板 |
| 工具栏添加角色 / 图形 / 机位 | 新增对象 → 加入列表 → 自动选中 → 视口聚焦 |
| 切换变换模式 | 视口 Gizmo 形态切换；仅选中对象时可操作 |
| 顶部切换视角 | 渲染相机与交互模式切换，左右面板内容不变 |
| 左侧切换可见性 | 视口中对应对象显隐，可撤销 |
| 机位面板「切换机位」 | 顶部切到机位视角并锁定为该机位 |
| 机位面板设置注视目标 | 机位持续朝向目标对象 |
| 工具栏切换画幅比例 | 视口取景框比例变化；`auto` 时不显示 |
| 场景清空 | 列表清空、取消选中、取景框复位 |

## 5. 验收标准

- [ ] 添加两个角色和一台机位，三者都出现在左侧列表并可分别选中。
- [ ] 角色导入后缩放显示为 1.0，点击角色任意部位选中的都是整个角色。
- [ ] 拖拽 Gizmo 移动对象，右侧位置数值实时跟随；反过来改数值，视口实时更新。
- [ ] 切到机位视角看到的画面与机位面板缩略图一致。
- [ ] 设置注视目标后移动目标对象，机位朝向自动跟随。
- [ ] 选择 16:9 取景框后，框外区域模糊；切回 `auto` 后取景框消失。
- [ ] 应用姿势预设后再拖动单个关节滑块，只有该关节变化。
- [ ] 连续操作后逐步撤销，能准确回到每一步之前的状态；重做同理。
- [ ] 清空场景后左侧列表显示空态引导，取景框按钮消失。
- [ ] 刷新页面后场景从自动保存恢复，且不影响 `/three-editor` 的场景。

## 6. 本期不做

- 场景面板的搜索框、分组 / 分类。
- 多机位并排预览 / 快速切换按钮组。
- 截图、拍照、导出、全屏按钮。
- 关键帧动画与运镜路径编排（当前只做静态摆位）。
- 角色之间的碰撞检测、IK 解算。
- 姿势数据的导入导出。
