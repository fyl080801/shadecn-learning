# REQ-FLOW 流程图画布

## 1. 目标

验证 Vue Flow 的交互定制能力：默认交互能不能被改成符合国内用户直觉的手感，节点样式能不能完全纳入项目的设计体系。

页面：`/vue-flow`。

## 2. 功能需求

### 2.1 画布

- 铺满可用区域，带网格背景（间距 16）。
- 左上角操作控件（缩放 / 适应视图 / 锁定）。
- 小地图，可拖拽、可缩放。
- 初始渲染时自动适应视图，但**最大放大到 1 倍**（Vue Flow 默认会放大到 4 倍，导致节点异常巨大），留 20% 内边距。

### 2.2 滚轮手感（核心定制点）

- **滚轮 = 垂直平移画布**（不是缩放）。
- **Ctrl + 滚轮 = 缩放**，以**光标位置为锚点**：缩放后光标底下的那个点保持不动。
- 禁用 Vue Flow 默认的 `zoomOnScroll` 和 `zoomOnPinch`，缩放逻辑自己实现。

> 为什么必须自己实现缩放：d3-zoom 的 `wheelDelta` 检测到 `ctrlKey` 会把 delta ×10（这是为触控板捏合准备的）。鼠标滚轮一格 `deltaY=120`，×10 之后一次滚动就顶到缩放上下限。去掉这个 ×10 后，手感才和 Vue Flow 默认滚轮缩放一致。
>
> 实现要点：在**捕获阶段**拦截 `wheel` 并 `preventDefault` + `stopPropagation`，这样 Vue Flow 自己的 wheel 处理不会再收到该事件；同时要按 `deltaMode` 归一化（像素 / 行 / 页）。

### 2.3 节点

- 自定义节点类型 `process`：圆角卡片，使用主题语义色（`bg-card` / `text-card-foreground` / `border`）。
- 选中态：主色边框 + 阴影 + 外发光环。
- 左侧 target 连接点、右侧 source 连接点。
- 最小宽度 128px，内容居中。

### 2.4 连线

- 连接模式为 `Strict`（只能 source → target）。
- 默认边类型 `smoothstep`，末端带实心箭头。
- 拖动一端连接点到另一节点即可建边，新建的边默认是**动画流动**样式。

### 2.5 添加节点

- 底部悬浮工具栏，一个「添加节点」按钮。
- 新节点出现在**画布中心**：屏幕坐标经 `screenToFlowCoordinate` 换算为画布坐标。
- 连续添加时按 24px 步长做层叠偏移（循环 6 次后归零），避免完全重叠；**第一个仍然正好在中心**。
- 节点的 `position` 是左上角坐标，要真正居中必须等节点渲染出尺寸后再换算 —— 用 `until(() => node.dimensions.width).toBeTruthy({ timeout: 1000 })` 等待，然后修正位置。
- 节点自动命名为「节点 N」。

## 3. 验收标准

- [ ] 滚轮上下滚动时画布平移，不缩放。
- [ ] Ctrl + 滚轮缩放时，光标底下的节点位置保持不动。
- [ ] 鼠标滚轮单次缩放幅度自然，不会一下顶到上下限。
- [ ] 首次进入时视图适配且节点保持原始大小（不被放大）。
- [ ] 连续点击「添加节点」，节点呈层叠分布而非重叠；第一个精确居中。
- [ ] 拖拽连接点能建边，边带箭头和流动动画。
- [ ] 节点在亮 / 暗两套主题下都正常显示，选中态清晰。

## 4. 本期不做

- 节点 / 边的删除、复制、撤销重做。
- 数据持久化（刷新即恢复初始的两个节点）。
- 节点内容编辑（label 固定）。
- 多种节点类型、条件分支、子流程。
- 自动布局（dagre / elk）。
- 导入导出 JSON、导出图片。
- 框选、对齐、吸附辅助线。
