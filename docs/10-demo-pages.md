# REQ-DEMO 演示页与小游戏

## 1. 目标

一组**轻量、自包含**的验证页面，每页只回答一个技术问题。它们的共同要求：

- 单文件（视图 + 至多一个配套组件）即可跑通，不引入新依赖；
- 优先用 shadcn-vue 的 `Card` 包一层，保持视觉一致；
- 不需要后端，不需要持久化（除非页面本身要验证持久化）。

## 2. 页面清单

### 2.1 Home `/`

- 项目入口，展示 Vite / Vue logo 和一个计数器。
- 用 `Card` / `Button` / `Badge` / `Separator` 验证 shadcn-vue 基础组件的引入方式与主题变量。
- 提供 Vue 官方文档外链。

### 2.2 关于（模态窗，无路由）

- 静态项目介绍：技术栈说明。已从 `/about` 页面改成侧栏用户菜单里弹出的模态窗（`src/components/AboutDialog.vue`），见 [REQ-SHELL](01-app-shell.md) 2.3。

### 2.3 打砖块 Demo3 `/demo3`

- Canvas 2D 实现的经典打砖块。
- 5 行 × 10 列彩色砖块（红 / 橙 / 黄 / 绿 / 蓝按行循环）。
- 3 条生命，右上角以 ❤️ 显示。
- 键盘控制挡板左右移动。
- 实时分数统计；状态机覆盖：开始 / 进行 / 暂停 / 结束 / 胜利。
- 当前**未挂进侧栏导航**，只能通过 URL 访问。

### 2.4 贪吃蛇 `/snake`

- Canvas 2D，20 × 20 网格，格子边长 20px（画布 400 × 400），带网格线。
- 初始移动间隔 150ms。
- 方向键控制；撞墙或撞到自己即结束。
- 分数 + 本次运行内的最高分（**内存中，刷新即丢**）。
- 支持暂停 / 继续。

### 2.5 2048 `/2048`

- 4 × 4 网格，方向键或滑动操作。
- 分数 + 最高分，最高分写入 `localStorage`（key: `bestScore2048`），**刷新后保留**。
- 游戏结束检测；达成 2048 后可选择继续。
- 使用 scoped CSS 自绘，不用 shadcn 组件 —— 这页验证的是"自定义样式页面也能和整体主题共存"。

### 2.6 机位角度 `/canvas3d`

- 验证目标：**不引 Three.js**，用纯 Canvas 2D 手写球面坐标投影，做一个可拖拽的机位方向控件。
- 在一个方块 + 网格的透视示意图上拖动机位点，改变 yaw / pitch。
- 支持配置：尺寸、移动速度、默认旋转、俯仰上下限、各元素颜色、暗色模式。
- `v-model` 输出 `{ yaw, pitch, zoomLevel }`；页面下方实时显示角度与缩放档位（In / Out / Normal）。
- 演示页把下限设为 55°、开启暗色模式。

### 2.7 光源方向 `/lightscene`

- 用 Three.js 渲染一个可拖拽的光源方向控件。
- 两种取景模式：**正面**（相机 `(0,0,6)`）与**透视**（相机 `(4,3,5)`），按钮切换。
- 支持吸附（snap）到规整角度。
- 拖动光源点改变打光方向，向外 `change` 事件抛出 `{ x, y, z }` 方向向量。

### 2.8 HTML in Canvas `/hic`

- 验证浏览器实验能力 `ctx.drawElementImage()` —— 把真实 DOM 子树绘制进 canvas。
- canvas 带 `layoutsubtree` 属性，子树是普通 HTML（表单 + 若干 div + 一个 shadcn `Card`）。
- 监听 canvas 的 `paint` 事件重绘，并把返回的 transform 写回子树元素。
- 用 `ResizeObserver` 以 `device-pixel-content-box` 监听尺寸，按设备像素设置 canvas 宽高，保证高分屏不糊。
- 类型声明放在 `src/canvas-extensions.d.ts`。
- **依赖实验性浏览器特性**，在不支持的浏览器上会白屏 —— 这是预期行为。
- 当前**未挂进侧栏导航**。

## 3. 验收标准

- [ ] 每个页面在亮 / 暗两套主题下均可正常阅读。
- [ ] 三个游戏的键盘事件在页面卸载时正确解绑，切走后不再响应按键。
- [ ] 游戏中的 `requestAnimationFrame` / 定时器在卸载时清理，不泄漏。
- [ ] 2048 的最高分刷新后仍在；贪吃蛇的最高分刷新后归零（符合各自设计）。
- [ ] `/canvas3d` 与 `/lightscene` 拖拽输出的角度数值与视觉表现一致。
- [ ] `/hic` 在支持 `drawElementImage` 的浏览器上能画出内容，高分屏下不模糊。

## 4. 本期不做

- 游戏的排行榜、存档、音效。
- 移动端触屏操作（2048 的滑动除外）。
- 页面之间的任何数据联动。
- `/hic` 的降级方案（不支持就是不支持）。
